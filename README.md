that links the three project pages:

- [act-tactile-page](https://theotaoliu.github.io/act-tactile-page/): Do Robots Need All Tactile Signals?

- [aloha2sim-page](https://theotaoliu.github.io/aloha2sim-page/): a MuJoCo twin of the lab ALOHA-2 workcell

The card images are loaded from those pages, so this repo holds no media of its own.
